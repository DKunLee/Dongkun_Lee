# Dongkun (DK) Lee — Personal Portfolio

Personal portfolio website for Dongkun (DK) Lee, Software Engineer & Machine Learning Researcher.

- **Live URL**: [https://DKunLee.github.io/Dongkun_Lee/](https://DKunLee.github.io/Dongkun_Lee/)
- **Tech Stack**: React 19, Vite 6, Tailwind CSS 4, Framer Motion, React Icons

---

## Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

---

## Deployment (GitHub Pages)

This repository is configured with automated GitHub Actions deployment located at `.github/workflows/deploy.yml`.

Whenever changes are committed and pushed to the `main` branch, GitHub Pages automatically builds and publishes the website.

To enable GitHub Pages in your repository settings:
1. Navigate to your repository on GitHub: `https://github.com/DKunLee/Dongkun_Lee/settings/pages`
2. Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. Push to `main`, and the deployment will run automatically!
